# Proyecto Escolar - Sistema de Gestión (Node.js + Express)

Este es un proyecto escolar desarrollado como parte de la asignatura de Desarrollo Web. El sistema está construido en **Node.js** utilizando el framework **Express**. Para el entorno de desarrollo se utiliza **nodemon**, lo que permite reiniciar el servidor automáticamente al detectar cambios en los archivos del proyecto.

## 🚀 Tecnologías Utilizadas

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [Nodemon](https://www.npmjs.com/package/nodemon)
